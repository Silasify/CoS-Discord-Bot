Snapping

Everything snaps to a grid. Walls, doorways and windows snap to the nearest cell edge, pillars to the nearest cell corner, and foundations, ramps, stairs, roofs and machines to the cell itself. The grid is drawn at the current level.

Saving your work

There are no accounts. Use Export JSON file to save, and Import file or Paste JSON to continue later or share with others. The page warns you if you try to leave with unexported changes.

File format

{
  "app": "salusa-blueprint",
  "version": 1,
  "name": "My base",
  "set": "fremen",
  "pieces": [ { "t": "foundation", "x": 0, "y": 0, "z": 0, "r": 0 } ]
}

Piece types: foundation, triangle, ramp, stairs, halfstairs, roof, hatch, dome, wall, doorway, window, railing, ladder, pillar, column, machine, light. r is 0–3 (north, east, south, west).
